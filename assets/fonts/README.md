# Banner display font

VT323 by Peter Hull is distributed under the SIL Open Font License 1.1. The complete license is in `OFL.txt`.

Source: https://github.com/google/fonts/tree/main/ofl/vt323

The banner follows the public ai-engineering-from-scratch website's `#3553ff` blueprint ink, `#fafaf5` paper, dotted grid, VT323 headings, and serif body text. The generator converts the bundled font's glyph commands to SVG paths, so exported SVGs and PNGs keep the same typography without requiring installed fonts or network access. The preview uses the same bundled font directly.
